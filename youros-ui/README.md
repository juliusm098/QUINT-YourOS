# YourOS UI

The user interface layer for YourOS providing:
- Desktop interface
- Mobile interface
- App launcher
- File manager
- Settings
- Notifications
- System tray

## Desktop

- Window management
- App switching
- File explorer
- System settings
- Notification center

## Mobile

- App drawer
- Quick settings
- Lock screen
- Home screen
- Notifications

## Project Structure

```
youros-ui/
├── desktop/            # Desktop UI
├── mobile/             # Mobile UI
├── components/         # Shared components
├── assets/             # Images and icons
└── styles/             # CSS/Styling
```
